## 三、任务入口设计说明

### 3.1 当前版本（V1.0）开放任务入口

Chat 页面任务选择器中，**仅开放以下 3 个办案任务入口**，其余任务做隐藏处理：

| 任务名称 | 对应核心场景 | 入口状态 |
|---------|------------|---------|
| 裁判文书 | 裁判文书生成 | **开放** |
| 庭审提纲 | 庭审提纲生成 | **开放** |
| 法条适用 | 法条检索与校验 | **开放** |

### 3.2 当前版本隐藏任务入口

以下任务在 V1.0 不做独立任务页面，入口隐藏，用户不可选择：

| 任务名称 | 隐藏原因 | 后续规划 |
|---------|---------|---------|
| 类案检索 | 非核心用户场景，底层能力支撑文书生成 | 作为底层能力嵌入文书生成流程 |
| 争议焦点 | 非核心用户场景，已融入庭审提纲 | 第二阶段独立模块 |
| 文本总结 | 通用任务，非办案核心 | 作为通用能力保留在后台 |
| 文本润色 | 通用任务，非办案核心 | 第二阶段"文风润笔"智能体替代 |
| 票据汇总 | 通用任务，非办案核心 | 第二阶段"票证智汇"智能体替代 |

### 3.3 尚未设计任务页面的核心能力

以下核心场景的能力在 V1.0 通过 Chat 自然语言交互触发，**暂无独立任务页面**：

| 核心场景 | 当前触发方式 | 独立页面规划 |
|---------|------------|------------|
| 文书质量评查 | 自然语言输入"评查这份文书" | 后续迭代评估 |
| 案由智能推荐 | 自然语言输入案情描述，系统自动推理 | 后续迭代评估 |
| 证据梳理 | 自然语言输入"梳理本案证据" | 后续迭代评估 |
| 知识问答 | 自然语言直接提问 | 保持Chat入口，不独立页面 |

## 四、页面结构规范

### 4.1 用户侧统一布局

所有用户侧页面采用统一的 **左侧导航（64px图标栏） + 顶部栏（64px） + 内容区** 布局：

```
┌─────────────────────────────────────────┐
│  侧边栏 │        顶部栏（页面标题）        │
│  64px   ├────────────────────────────────┤
│         │                                │
│  💬 聊天 │         内容区                 │
│  ✅ 任务 │         （自适应）              │
│  📁 案件 │                                │
│  📝 文书 │                                │
│  📚 知识 │                                │
│         │                                │
└─────────┴────────────────────────────────┘
```

### 4.2 管理后台统一布局

所有管理后台页面采用统一的 **侧边栏（260px） + 顶部导航（64px） + 内容区** 布局：

```
┌─────────────────────────────────────────┐
│  侧边栏    │        顶部导航栏            │
│  260px     ├─────────────────────────────┤
│            │                             │
│  Logo      │         内容区              │
│  ────────  │         （自适应）           │
│  控制台    │                             │
│  用户管理  │                             │
│  ...      │                             │
│            │                             │
└────────────┴─────────────────────────────┘
```
