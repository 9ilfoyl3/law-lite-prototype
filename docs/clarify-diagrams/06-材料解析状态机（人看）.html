材料解析状态机（V1.1）
文件从上传到解析完成的状态流转与异常处理路径；单文件粒度的状态机，案件级别聚合后影响文书生成按钮可用性
一、状态机流转（PRD 10.1 / 10.2）
主路径 / 重新解析 成功路径 异常路径 重新上传 / 回退 删除路径
二、5 种异常类型与处理（PRD 10.3）
异常类型 表现 用户处理路径
格式不支持 文件名旁黄色标签"格式不支持" 重新上传支持的格式（PDF / Word / Excel / TXT / 图片）
文件损坏 黄色标签"文件损坏" 重新上传完整文件
OCR 失败 黄色标签"OCR失败"（扫描件） 重新上传可编辑版（非扫描件）
内容为空 黄色标签"内容为空" 检查文件内容后重新上传
文件过大 上传时拦截，不进入解析 上传符合大小限制的文件（大小限制由系统初始化配置）
三、进度展示区分（PRD 10.4）

📋 案件列表页

  • 材料数量单元格：解析中显示 spinner + 数字
  • 异常材料数单独 标黄
  • 点击材料数量 → 打开"文件解析状态"弹窗
  • 弹窗展示每个文件的解析状态
  • 弹窗中对异常文件提供"重新解析"按钮

📁 案件详情页

  • 材料树仅展示 parseStatus === 'success' 的材料
  • 解析中和异常材料不在详情页展示
  • 顶部进度概览："共 N 个文件，已解析 M 个，异常 K 个"
  • 仅在存在未解析完成或异常文件时显示概览
  • 查看全部文件状态 → 列表页文件解析状态弹窗
四、交互规则（PRD 10.5）
规则 说明
解析触发 文件上传完成后自动触发解析（原型阶段 mock 延时 2-3 秒模拟异步）
解析中不可生成文书 列表页"生成文书"按钮在材料解析中时置灰，提示"材料解析中，请稍候"
详情页材料过滤 案件详情页材料树仅展示 parseStatus === 'success' 的文件，解析中和异常文件不展示（详见 5.2 功能1）
部分异常不阻塞 只要存在已解析成功的材料，即可生成文书；异常材料自动排除
批量解析 批量上传时并行解析，互不影响
重新解析 在文件解析状态弹窗中，对异常文件提供"重新解析"按钮（原文件重试）
