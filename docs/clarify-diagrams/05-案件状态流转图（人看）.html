一、状态机流转（PRD 8.1 / 8.2）
主链路流转 生成文书 异常路径 回退/旁路 删除操作
二、列表页视觉标识（PRD 8.1）
材料数量 文书数 用户感知状态 列表页视觉标识
0 0 待上传 材料数量单元格显示 - 灰色
> 0 0 待生成 材料数量显示数字 正常色；解析中显示 spinner + 数字；异常份数单独 标黄
> 0 ≥ 1 已生成 材料数量显示数字 + 案件名称后 蓝色文书数徽章；点击徽章打开历史文书弹窗
材料数量包含：已解析材料 + 解析异常材料（异常单独标黄）；文书数包含该案件下所有文书类型、所有版本的文书总数。不加状态筛选器，用户通过材料数量/文书数自行判断。

批量生成

Token 超限不再做前置判断，改为调用 workflow 后根据返回异常展示提示（详见 6.4）；批量生成另受"系统初始化配置"中"批量文书队列允许个数"限制（默认 10）。
